Move the Motive tracker into the Nucleus

Brings everyone's sales owners, stages, notes, system names and email templates across from the old Motive Upgrade Planner site, without losing anything. Administrators only. Help · v1.0.0

1 Get the latest data from the old site

Enter the old site's address, then open its data. Your browser will ask for the old site's password if it doesn't remember it.

Open the old site's data

It opens as a page of text starting {"ok":true,"collections":. Select it all (Ctrl+A / ⌘A), copy, and paste it below. Or save it as a file and choose it below.

2 Check what will change

3 Import

For each record, the newer version wins (by when it was last changed); anything already only in the Nucleus is kept. You can run this as many times as you like: import now, then again just before you switch the old site off, to pick up last-minute changes.

Help · v1.0.0
  • Who can use this page: Nucleus administrators (the NUCLEUS_ADMINS list in Netlify).
  • What moves: the campaign (sales owner, stage, notes), system names and assignments, email templates and settings. Licence data itself comes from the sheet and Pipedrive, so it doesn't need moving.
  • Each person picks their name in the Motive tool's “You are” menu once; the Nucleus then remembers it with their account on every device.
  • v1.0.0 (6 Nov 2026): first release.
